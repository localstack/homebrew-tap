# The LocalStack Homebrew Tap

This is a custom [Homebrew](https://brew.sh) tap for official LocalStack software.

## Installing lstk

[`lstk`](https://github.com/localstack/lstk) is the official LocalStack CLI. It manages the full emulator lifecycle: authentication, image pulls, container lifecycle, logs, and state snapshots.

Install it on macOS or Linux with:

```bash
brew install localstack/tap/lstk
```

This also installs shell completions for `bash`, `zsh`, and `fish`.

Verify the installation:

```bash
lstk --version
```

Then start LocalStack:

```bash
lstk
```

Running `lstk` without arguments authenticates, pulls the latest image if needed, and starts the container.

## Updating lstk

`lstk` updates itself through the method you installed it with:

```bash
lstk update --check  # check without installing
lstk update          # install the latest version
```

You can also update it through Homebrew:

```bash
brew upgrade localstack/tap/lstk
```

## Installing the legacy LocalStack CLI

> [!WARNING]
> The [legacy LocalStack CLI](https://docs.localstack.cloud/aws/developer-tools/running-localstack/localstack-cli/) is deprecated. Use `lstk` instead.

The binary package of the legacy CLI (built in [`localstack/localstack-cli`](https://github.com/localstack/localstack-cli)) is still available:

```bash
brew install localstack/tap/localstack-cli
```

## Additional Information and Problem Reporting

The `lstk` cask is generated by [GoReleaser](https://goreleaser.com) and the `localstack-cli` formula by [Homebrew Releaser](https://github.com/Justintime50/homebrew-releaser). Both are created and updated automatically on release.

If you are experiencing issues with a cask or formula, please create an issue in the respective repository.
